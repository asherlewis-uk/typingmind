Brand Overview

Logo Usage

The nexumChat logo consists of a connected-node "N" mark. The mark uses the brand gradient by default and can be used in monochrome for restricted applications.

  • Minimum clear space: equal to the height of one node around all sides
  • Minimum size: 16px for digital, 0.25in for print
  • Do not distort, rotate, or recolor the gradient without approval
  • Monochrome version should use the text color of its context

Configuration Notes

When deploying these assets, update the following configuration files in your project:

  • src/manifest.json - Update name, short_name, icon paths
  • src/browserconfig.xml - Update tile icon paths
  • src/index.html - Update OG image, title, description
  • backend/config/config.json - Update brand, logoURL
  • capacitor.config.json - Update appId, appName
